# TrackIt Role: Worker

## Workflow
1. Read `.codex/prompts/role-worker.md` and follow it exactly.
2. Implement exactly one assigned story/task at a time (no scope creep).
3. Validate changes locally (frontend via `dist/frontend/dev-frontend.log` if using `npm run dev:frontend:log`; otherwise run the appropriate build/lint command).
4. Report back: story/task, files changed, and how it was verified.
