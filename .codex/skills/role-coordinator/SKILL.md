# TrackIt Role: Coordinator

## Workflow
1. Read `.codex/prompts/role-coordinator.md` and follow it exactly.
2. Prefer planning/coordination work over code changes unless explicitly asked.
3. Write/update feature docs: `docs/feature/<feature-name>.md` and `docs/feature/<feature-name>.impl.md`.
4. Produce small worker tickets (scope + acceptance + verification) and keep the relevant `.impl.md` checklist current.
