# Specs

This directory stores Ralph loop requirement specs for TrackIt.

Guidelines:
- Create one markdown file per topic of concern.
- Keep each spec focused enough to describe in one sentence without combining unrelated capabilities.
- Prefer concrete behaviors, acceptance criteria, and constraints over brainstorming.
- Treat these files as the durable requirements input for `PROMPT_plan.md` and `PROMPT_build.md`.

Suggested structure:
- Summary
- User or operator job to be done
- Required behaviors
- Acceptance criteria
- Out of scope
